# EducaLinks

Plataforma escolar para compartilhamento de atividades e links educacionais.

---

# COMO EXECUTAR

1. Abra a pasta do projeto no VSCode

2. Instale a extensão:
   Live Server

3. Clique com botão direito em:
   index.html

4. Clique:
   Open with Live Server
